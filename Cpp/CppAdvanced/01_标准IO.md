# C/C++ 底层进阶笔记：标准 I/O 与文件 I/O 深度解析

---

## 一、 I/O 核心概念与分类

### 1. I/O 的本质
* **概念**：I/O（Input/Output）顾名思义就是输入与输出。程序与外部设备（如磁盘、终端、网络）进行信息交换的过程就称为 I/O 操作。
* **初识**：我们最先接触的 I/O 是 `#include <stdio.h>`。它的全称其实是：**标准的缓冲输入输出头文件** (Standard Buffered Input/Output)。

### 2. 标准 I/O 与文件 I/O 的分类对比
* **文件 I/O（系统调用）**：
  * 基于操作系统内核提供的系统调用完成。
  * **痛点**：每进行一次系统调用，进程就会发生一次“上下文切换”（从**用户空间**陷入**内核空间**），这会导致进程短暂挂起。频繁调用会导致极高的系统开销，程序执行效率低下。
  * **常见接口**：`open` / `close`, `read` / `write`, `lseek`
* **标准 I/O（库函数）**：
  * 使用 C 标准库提供的函数实现。
  * **核心优势（引入缓冲区）**：标准 I/O 在文件 I/O 的基础上封装了一层**缓冲区**。用户的数据会先在用户空间的缓冲区中暂存，等达到特定条件（如缓冲区满、遇到换行符或手动刷新）时，才会统一进行一次系统调用，将数据批量刷入内核空间。这极大地减少了系统调用的次数，提升了效率。
  * **常见接口**：`printf` / `scanf`, `fopen` / `fclose`, `fgetc` / `fputc`, `fgets` / `fputs`, `fprintf` / `fscanf`, `fread` / `fwrite`

## 二、 标准 I/O 的核心：`FILE` 结构体

### 1. `FILE` 结构体简介
`FILE` 是 C 标准库提供的一个极其重要的结构体，它内部记录了一个打开的文件的所有状态信息（如缓冲区地址、读写指针位置、底层的文件描述符等）。

### 2. 底层原型预览（简化版）
```c
struct FILE {
    char * _IO_buf_base;  // 缓冲区的起始地址
    char * _IO_buf_end;   // 缓冲区的终止地址
    int _fileno;          // 核心！底层的文件描述符，用于真正进行系统调用
    // ... 其他状态标志位
};
```

### 3. 三大特殊 `FILE` 指针（终端专属）
当程序启动时，系统会自动为你打开三个特殊的文件指针：
* `stdin`：标准输入指针（默认绑定键盘）
* `stdout`：标准输出指针（默认绑定显示器屏幕）
* `stderr`：标准出错指针（默认绑定显示器屏幕，无缓冲，立刻输出）

## 三、 文件的打开与关闭：`fopen` / `fclose`

### 1. 打开文件：`fopen`
* **头文件**：`#include <stdio.h>`
* **原型**：`FILE *fopen(const char *path, const char *mode);`
* **功能**：打开指定路径的文件，并返回该文件的 `FILE` 指针。
* **参数解析**：
  * `path`：文件路径字符串。
  * `mode`：打开模式，详见下表：

| 模式 | 操作权限 | 文件不存在时的行为 | 文件存在时的行为 | 光标初始位置 |
| :--- | :--- | :--- | :--- | :--- |
| **r** | 只读 | 报错返回 NULL | 正常打开 | 文件开头 |
| **r+**| 读写 | 报错返回 NULL | 正常打开 | 文件开头 |
| **w** | 只写 | **自动创建新文件** | **清空文件原内容** | 文件开头 |
| **w+**| 读写 | **自动创建新文件** | **清空文件原内容** | 文件开头 |
| **a** | 追加写 | **自动创建新文件** | 正常打开 | **文件末尾** |
| **a+**| 读 / 追加写 | **自动创建新文件** | 读在开头，写在末尾 | 读开头 / 写末尾 |

* **返回值**：成功返回有效文件指针；失败返回 `NULL` 并自动设置内核的错误码（`errno`）。

### 2. 关闭文件：`fclose`
* **头文件**：`#include <stdio.h>`
* **原型**：`int fclose(FILE *fp);`
* **功能**：关闭指定的文件，刷新缓冲区，释放系统资源。
* **返回值**：成功返回 0；失败返回 `EOF` (-1) 并设置错误码。

### 💻 综合代码示例：打开与关闭
```c
#include <stdio.h>

int main() {
    // 1. 以只写模式 (w) 打开文件。如果不存在则创建，如果存在则清空。
    FILE *fp = fopen("test_log.txt", "w");
    
    // ⚠️ 防御性编程：必须检查文件是否成功打开！
    if (fp == NULL) {
        printf("打开文件失败！\n");
        return -1;
    }
    
    printf("文件打开成功，可以进行写入操作...\n");
    // 这里执行各种读写操作...
    
    // 2. 操作完毕，必须关闭文件，否则会造成内存泄漏和文件锁死
    int res = fclose(fp);
    if (res == 0) {
        printf("文件安全关闭。\n");
    }
    
    return 0;
}
```

## 四、 内核错误码机制与处理

### 1. 概念与常用错误码补充
当内核或库函数执行出错时，系统会向用户空间反馈一个整型错误编号，存储在全局变量 `errno` 中（需包含 `<errno.h>`）。错误码总是大于或等于 0。
* `0`：成功 (Success)
* `1`：操作不允许 (EPERM - Operation not permitted)
* **`2`：文件或目录不存在 (ENOENT - No such file or directory)** * **`13`：权限不够 (EACCES - Permission denied)**
* `17`：文件已存在 (EEXIST - File exists)
* `22`：无效的参数 (EINVAL - Invalid argument)
* `28`：设备上没有空间 (ENOSPC - No space left on device)

### 2. 错误处理两大神器：`strerror` 与 `perror`
由于记住数字太反人类，C 语言提供了两个函数来翻译这些错误码。

* **`strerror` (需包含 `<string.h>`)**
  * 原型：`char* strerror(int errnum);`
  * 功能：将指定的错误码数字转换为人类可读的字符串描述。
* **`perror` (需包含 `<stdio.h>`)**
  * 原型：`void perror(const char *s);`
  * 功能：极简报错神器。它会自动读取当前全局的 `errno`，输出你自定义的提示词 `s`，自动加上冒号，并拼接出对应的错误信息，最后自动换行。

### 💻 代码示例：触发并捕获错误
```c
#include <stdio.h>
#include <errno.h>
#include <string.h>

int main() {
    // 故意以只读 (r) 模式打开一个不存在的文件，必然失败
    FILE *fp = fopen("not_exist_file.txt", "r");
    
    if (fp == NULL) {
        // 方法 1：使用 strerror 手动提取错误信息
        printf("【手动获取】错误码: %d, 错误原因: %s\n", errno, strerror(errno));
        
        // 方法 2：使用 perror 极简输出（工程中最常用）
        perror("【自动报错】打开文件失败"); 
        
        return -1;
    }
    
    fclose(fp);
    return 0;
}
```
*(预期输出：`【自动报错】打开文件失败: No such file or directory`)*

## 五、 单字符读写：`fgetc` / `fputc`

### 1. 写入单个字符：`fputc`
* **原型**：`int fputc(int c, FILE *stream);`
* **功能**：将指定的字符写入到文件流中。
* **参数**：
  * `c`：要写入的字符（底层以 ASCII 码整型形式传递）。
  * `stream`：目标文件指针。
* **返回值**：成功返回写入的字符值；失败返回 `EOF` (-1)。

### 2. 读取单个字符：`fgetc`
* **原型**：`int fgetc(FILE *stream);`
* **功能**：从指定文件中读取下一个字符，内部的“文件光标”会自动向后移一位。
* **返回值**：成功返回读取到的字符值；如果读到了文件末尾或发生错误，返回 `EOF` (-1)。

### 💻 综合代码示例：字符逐个拷贝
```c
#include <stdio.h>

int main() {
    // 第一阶段：向文件写入几个字符
    FILE *fp_out = fopen("char_test.txt", "w");
    if (fp_out == NULL) {
        perror("创建文件失败");
        return -1;
    }
    fputc('H', fp_out);
    fputc('i', fp_out);
    fputc('\n', fp_out); // 写入换行符
    fclose(fp_out); // 关闭，此时数据刷入磁盘

    // 第二阶段：从文件读取字符，并打印到屏幕
    FILE *fp_in = fopen("char_test.txt", "r");
    if (fp_in == NULL) {
        perror("打开文件失败");
        return -1;
    }

    int ch;
    printf("开始读取文件内容：\n");
    // 核心用法：循环读取，直到遇到 EOF (End Of File)
    while ((ch = fgetc(fp_in)) != EOF) {
        // 将读到的字符打印到标准输出设备（屏幕）
        fputc(ch, stdout); 
    }
    
    fclose(fp_in);
    return 0;
}
```

## 六、 字符串读写：`fgets` / `fputs`

相较于单字符读写，按“字符串（行）”读写在实际工程中处理配置文件、日志文件时最为常用。

### 1. 写入字符串：`fputs`
* **原型**：`int fputs(const char *s, FILE *stream);`
* **功能**：将指定的字符串（以 `\0` 结尾）写入到指定的文件流中。
* **参数**：
  * `s`：要被写入的字符串首地址。
  * `stream`：目标文件指针。
* **返回值**：成功返回一个非负整数（通常是写入的字符个数）；失败返回 `EOF` (-1)。
* **⚠️ 核心避坑（与 `puts` 的区别）**：
  * 标准输出的 `puts("hello")` 会自动在末尾帮你加一个换行符 `\n`。
  * 但 **`fputs` 绝对不会自动追加换行符！** 你传进去什么它就写什么。如果你需要换行，必须在字符串里手动写上 `\n`（例如：`fputs("hello\n", fp);`）。

### 2. 读取字符串：`fgets`
* **原型**：`char *fgets(char *s, int size, FILE *stream);`
* **功能**：从文件中按行读取字符串，存入指定的字符数组容器中。
* **参数**：
  * `s`：字符数组容器的起始地址。
  * `size`：要读取的最大容量。**为了保证安全，最多只会从文件中读取 `size - 1` 个字符**。
  * `stream`：源文件指针。
* **返回值**：成功返回容器 `s` 的起始地址；失败或读到文件末尾（EOF）且未读到任何数据时，返回 `NULL`。
* **💡 核心机制（它是如何停止读取的？）**：
  `fgets` 每次读取会在遇到以下三种情况之一时停下来：
  1. **读够了大小**：读满了 `size - 1` 个字符。
  2. **遇到了换行**：读到了回车换行符 `\n`。**（注意：它会将这个 `\n` 一并存入你的容器 `s` 中！）**
  3. **遇到了结尾**：读到了文件末尾（EOF）。
  *不管因为哪种原因停下来，`fgets` 都会极其尽责地在存入数据的最后，**自动补上一个字符串结束标志 `\0`***。

### 💻 综合代码示例：按行写入与读取
```c
#include <stdio.h>
#include <string.h>

int main() {
    // -----------------------------------------
    // 第一阶段：使用 fputs 写入多行字符串
    // -----------------------------------------
    FILE *fp_out = fopen("string_log.txt", "w");
    if (fp_out == NULL) {
        perror("打开文件写入失败");
        return -1;
    }
    
    // 注意：fputs 不会自动换行，需要手动在末尾加上 \n
    fputs("Hello, standard I/O!\n", fp_out);
    fputs("This is the second line.\n", fp_out);
    fputs("Line 3 without newline ending.", fp_out); // 这一行没加换行符
    
    fclose(fp_out);
    printf("字符串写入完成！\n\n");

    // -----------------------------------------
    // 第二阶段：使用 fgets 按行读取字符串
    // -----------------------------------------
    FILE *fp_in = fopen("string_log.txt", "r");
    if (fp_in == NULL) {
        perror("打开文件读取失败");
        return -1;
    }

    char buffer[64]; // 定义一个容量为 64 字节的接收容器
    int line_num = 1;
    
    printf("开始按行读取内容：\n");
    // 核心用法：循环判断 fgets 的返回值是否为 NULL
    while (fgets(buffer, sizeof(buffer), fp_in) != NULL) {
        /*
         * 细节注意：如果文件中本身有换行符，buffer 里面已经包含 '\n' 了。
         * 此时如果用 printf("%s\n", buffer)，会导致输出两个空行。
         * 所以直接打印 "%s" 即可。
         */
        printf("第 %d 行: %s", line_num, buffer);
        line_num++;
    }
    
    printf("\n\n文件读取结束。\n");
    fclose(fp_in);
    
    return 0;
}
```

## 七、 标准 I/O 的缓冲区机制（核心考点）

标准 I/O 相比系统调用之所以高效，完全归功于“缓冲区”。了解它的刷新机制，是排查“为什么 printf 没打印出来”这类玄学 Bug 的关键。

### 1. 缓冲区的分类与大小
标准 I/O 的缓冲区分为三种类型，它们在内存大小和针对的对象上完全不同：

* **① 行缓存 (Line Buffered)**
    * **对象**：专门针对终端（显示器、键盘）相关的文件指针（如 `stdin`, `stdout`）。
    * **大小**：通常为 **1024 字节** (1KB)。
    * *注意：如果缓冲区从未被使用，其分配大小为 0；只有至少发生一次 I/O 操作后，才会真正分配内存。*
* **② 全缓存 (Fully Buffered)**
    * **对象**：针对普通的磁盘文件（即通过 `fopen` 打开返回的普通的 `fp`）。
    * **大小**：通常为 **4096 字节** (4KB)。
* **③ 不缓存 (Unbuffered)**
    * **对象**：专门针对标准错误输出（`stderr`），确保报错信息第一时间显示。
    * **大小**：**0 字节**（来多少直接输出多少）。

---

### 2. 缓冲区的刷新时机 (Flush Triggers)

#### ① 行缓存的刷新时机 (以 `stdout` 为例)
* **a. 遇到换行符 `\n` 时（最常见）**
    ```c
    printf("hello world\n"); // 立刻输出
    while(1);
    ```
* **b. 缓冲区写满时 (满 1024 字节)**
    ```c
    for(int i = 0; i < 1025; i++) {
        printf("A"); 
    }
    while(1); // 终端只会印出 1024 个 A，第 1025 个被憋在缓冲区里
    ```
* **c. 发生 I/O 切换时（如从输出切换到输入）**
    ```c
    printf("请输入密码:"); // 没有 \n，但因为下一句是 scanf，系统会强制刷新输出
    int num;
    scanf("%d", &num);
    ```
* **d. 手动调用 `fflush` 时**
    ```c
    printf("Loading..."); // 没有 \n
    fflush(stdout);       // 强制把 Loading... 刷到屏幕上
    while(1);
    ```
* **e. 正常关闭文件流 (`fclose`) 或 程序正常结束 (`return 0` / `exit`) 时。**
    *(注意：如果用 `while(1)` 死循环卡住且不满足上述条件，数据将永远不显示。)*

#### ② 全缓存的刷新时机 (以普通文件 `fp` 为例)
* **a. 缓冲区写满时 (满 4096 字节)**
    ```c
    for(int i = 0; i < 4097; i++) {
        fputs("A", fp); 
    }
    // 前 4096 个字节被刷入磁盘，第 4097 个留在内存缓冲区
    ```
* **b. 手动调用 `fflush` 或 `fclose` 关闭文件时**
    ```c
    fputs("hello", fp);
    fclose(fp); // 此时 "hello" 才会真正写入磁盘文件
    ```
* **c. 发生 I/O 切换时（从写切换到读）**
    ```c
    fputs("hello", fp);
    fgetc(fp); // 准备读文件，系统会先把刚才写的 hello 刷到磁盘
    ```
* **d. 程序正常结束时。**
* **⚠️ 核心区别：全缓存遇到 `\n` 是绝对不会刷新的！** #### ③ 不缓存的刷新时机 (`stderr`)
* **放入即刷新：** 只要有数据进入，不等待，立刻输出到底层设备。
    ```c
    fputs("Error occurred!", stderr); // 立刻弹到屏幕上，不受死循环影响
    while(1);
    ```

## 八、 格式化读写：`fprintf` / `fscanf`

这对函数是处理结构化日志、配置文件最强大的工具，它们的作用是将数据与文件进行直接交互。

### 1. 格式化写入：`fprintf`
* **原型**：`int fprintf(FILE *stream, const char *format, ...);`
* **功能**：按照指定的格式控制符（如 `%d`, `%s`），将变量组合成字符串，并输出到指定文件中。
* **返回值**：成功返回写入的字符总数；失败返回负数。

#### 💻 `fprintf` 代码示例：
```c
#include <stdio.h>

int main() {
    FILE *fp = fopen("user_info.txt", "w");
    if (fp == NULL) return -1;

    char name[] = "Alice";
    int age = 25;
    double score = 98.5;

    // 核心用法：像用 printf 一样，只是最前面加了个文件指针
    fprintf(fp, "Name: %s, Age: %d, Score: %.1f\n", name, age, score);
    
    fclose(fp);
    return 0;
}
```

### 2. 格式化读取：`fscanf`
* **原型**：`int fscanf(FILE *stream, const char *format, ...);`
* **功能**：从文件中提取文本数据，按照指定的格式控制符，解析并转换成特定的数据类型，存入程序变量中。
* **返回值**：成功返回成功匹配并赋值的变量个数；失败或读到文件末尾返回 `EOF` (-1)。

#### 💻 `fscanf` 代码示例：
```c
#include <stdio.h>

int main() {
    FILE *fp = fopen("user_info.txt", "r"); // 假设读取上面生成的文件
    if (fp == NULL) return -1;

    char parsed_name[50];
    int parsed_age;
    double parsed_score;

    // 核心用法：格式控制符必须和文件里的文本格式一模一样才能精准提取
    // 注意：变量前面必须加取地址符 &（数组名除外）
    int count = fscanf(fp, "Name: %s, Age: %d, Score: %lf\n", parsed_name, &parsed_age, &parsed_score);
    
    if (count == 3) {
        printf("成功解析了 %d 个数据！\n", count);
        printf("提取到内存: %s, %d, %.1f\n", parsed_name, parsed_age, parsed_score);
    }
    
    fclose(fp);
    return 0;
}
```

## 九、 字符串格式化（内存打印）：`sprintf` / `snprintf`

这组函数**不操作文件**，而是把格式化的数据打印到**内存中的字符数组（字符串）**里。

### 1. 危险的 `sprintf`
* **原型**：`int sprintf(char *str, const char *format, ...);`
* **功能**：将各类变量格式化为字符串，拼接后存入 `str` 指向的字符数组中。
* **痛点**：如果不小心格式化出来的字符串长度，超过了目标容器 `str` 的容量，就会发生**指针越界（缓冲区溢出）**，直接导致段错误（Segment Fault）。在现代工程中被视为危险函数。

### 2. 安全的替代者：`snprintf` (强烈推荐)
* **原型**：`int snprintf(char *str, size_t size, const char *format, ...);`
* **功能**：与 `sprintf` 相同，但多了一个 `size` 参数，强制限制最多只能向目标数组写入 `size - 1` 个有效字符，最后一位永远自动留给结束符 `\0`。
* **返回值**：如果空间足够，返回实际转换的字符数；如果空间不足被截断，返回**本应该写入的字符总数**。失败返回负数。

#### 💻 `snprintf` 防溢出代码示例：
```c
#include <stdio.h>

int main() {
    char buffer[10]; // 定义一个极小的容器，只能装 9 个可见字符 + 1 个 '\0'
    int year = 2026;
    char word[] = "Programming";

    // 试图把 "Year: 2026, Word: Programming" (远远超过10个字符) 塞进去
    // 使用 snprintf 保护内存，最多只写 9 个字符
    int ret = snprintf(buffer, sizeof(buffer), "Year: %d, Word: %s", year, word);

    printf("实际存入 buffer 的内容: [%s]\n", buffer); 
    // 输出: [Year: 202] （被完美截断，没有发生越界崩溃）
    
    printf("如果空间足够，本来应该写入的长度: %d\n", ret); 

    return 0;
}
```

十一、关于文件光标 fseek/ftell/rewind
int fseek(FILE *stream, long offset, int where);
功能：移动文件光标位置，将光标从指定位置处进行前后偏移
参数1：文件指针
参数2：偏移量
>0: 表示从指定位置向后偏移n个字节
<0: 表示从指定位置向前偏移n个字节
=0: 不偏移
参数3：偏移的起始位置
SEEK_SET:文件起始位置
SEEK_CUR:文件指针当前位置
SEEK_END:文件结束位置
返回值：成功返回0，失败返回-1并置位错误码

long ftell(FILE *stream)
功能：获取文件指针当前的偏移量
参数：文件指针
返回值：成功返回文件指针所在的位置，失败返回-1并置位错误码
eg:fseek(fp, 0, SEEK_END);  //将光标定位在结尾
   ftell(fp);   //该函数的返回值，就是文件大小

void rewind(FILE *stream);
功能：将文件光标定位在开头
参数：文件指针
返回值：无
