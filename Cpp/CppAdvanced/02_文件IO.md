## 一、 文件 I/O 的核心本质

* **底层机制**：文件 I/O 是通过操作系统提供的**系统调用**（内核函数）直接实现的。
* **性能代价**：只要使用了文件 I/O 接口，进程就会发生一次“上下文切换”——从**用户空间**陷入**内核空间**。由于文件 I/O 本身没有用户态缓冲区的概念，如果频繁读写少量数据，效率会极低。
* **常用操作**：`open`, `close`, `read`, `write`, `lseek`。
* *(注：我们常用的 C 语言标准 I/O（如 `fopen`, `printf`）在底层其实也封装了这些文件 I/O 操作，只是加了一层缓冲区来减少切换次数。)*

---

## 二、 文件描述符 (File Descriptor, FD)

* **概念**：文件描述符的本质是一个**无符号整数**。当使用 `open` 函数成功打开一个文件时，内核会返回一个用于后续操作该文件的“句柄”，这就是文件描述符。
* **数量限制**：
  * 在一个进程中，默认能够打开的文件描述符数量是有限的，一般是 **[0, 1023]**（共 1024 个）。
  * 查看当前限制：终端输入 `ulimit -a`。
  * 临时修改限制：终端输入 `ulimit -n 2048`。
* **分配原则**：**最小未分配原则**。（即系统总是把当前尚未被使用的最小整数分配给新打开的文件）。
* **默认开启的特殊 FD**（极其重要）：
  * **`0`**：标准输入 (`stdin`)
  * **`1`**：标准输出 (`stdout`)
  * **`2`**：标准出错 (`stderr`)

## 三、 打开与关闭文件：`open` / `close`

### 1. `open` 函数详解
```c
#include <sys/types.h>
#include <sys/stat.h>
#include <fcntl.h>

// 形式 1：用于打开已有文件
int open(const char *pathname, int flags);

// 形式 2：用于创建新文件（带 O_CREAT 标志时，必须传入 mode 参数）
int open(const char *pathname, int flags, mode_t mode);
```

**参数解析：**
* **`pathname`**：要打开的文件路径。
* **`flags`**：打开模式。**前三个必须且只能选其一**：
  * `O_RDONLY`：只读
  * `O_WRONLY`：只写
  * `O_RDWR`：读写
  * **可选附加标志（用 `|` 按位或连接）**：
    * `O_CREAT`：文件不存在则创建（必须加上第三个参数 `mode`）。
    * `O_APPEND`：追加模式，每次写操作光标自动定位到文件末尾。
    * `O_TRUNC`：清空文件，打开时将文件长度截断为 0。
    * `O_EXCL`：常与 `O_CREAT` 连用，确保一定是**新建**文件。如果文件已存在，则报错返回 -1（用于防止覆盖重要文件）。
* **`mode`**：文件权限（如 `0664`）。
  * 实际创建出来的权限并不完全等于你给定的值，而是受系统的掩码影响。计算公式为：**最终权限 = `mode & ~umask`**。
  * `umask` 默认一般为 `0022`，可通过命令 `umask` 查看。
  * 如果带了 `O_CREAT` 却不给这个参数，创建出来的文件权限将是乱码（随机值）。

**💡 标准 I/O 模式对应底层 open 的标志组合（精准无误版）：**
* `"r"`  等价于 `O_RDONLY`
* `"r+"` 等价于 `O_RDWR`
* `"w"`  等价于 `O_WRONLY | O_CREAT | O_TRUNC`
* `"w+"` 等价于 `O_RDWR | O_CREAT | O_TRUNC`
* `"a"`  等价于 `O_WRONLY | O_CREAT | O_APPEND`
* `"a+"` 等价于 `O_RDWR | O_CREAT | O_APPEND`

### 💻 代码示例：安全的打开与关闭
```c
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>

int main() {
    // 模拟 "w+" 模式：读写打开，不存在则创建，存在则清空，权限为 rw-rw-r-- (0664)
    int fd = open("system.log", O_RDWR | O_CREAT | O_TRUNC, 0664);
    
    if (fd == -1) {
        perror("open 失败");
        return -1;
    }
    
    printf("文件打开成功，分配的文件描述符为: %d\n", fd);
    
    // 操作完毕，必须释放文件描述符！
    close(fd); 
    return 0;
}
```

## 四、 读写操作：`read` / `write`

这两兄弟是直接与设备对话的桥梁，不仅能读写普通文件，还能读写硬件设备节点（如串口、网络套接字）。

### 1. `write` 函数
```c
#include <unistd.h>
ssize_t write(int fd, const void *buf, size_t count);
```
* **功能**：将 `buf` 指向的内存中前 `count` 个字节，写入到 `fd` 对应的文件中。
* **返回值**：成功返回**实际**写入的字节数；失败返回 `-1`。

### 2. `read` 函数
```c
#include <unistd.h>
ssize_t read(int fd, void *buf, size_t count);
```
* **功能**：从 `fd` 中读取最多 `count` 个字节，存入 `buf` 容器中。
* **返回值**：成功返回**实际**读取到的字节数（有可能小于你请求的 `count`，比如读到了文件末尾）；返回 `0` 表示文件读到了尽头（EOF）；失败返回 `-1`。

### 💻 代码示例：实现简单的文件拷贝
```c
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>

int main() {
    int fd_in = open("source.txt", O_RDONLY);
    int fd_out = open("dest.txt", O_WRONLY | O_CREAT | O_TRUNC, 0644);
    
    if (fd_in == -1 || fd_out == -1) return -1;

    char buffer[1024]; // 在用户空间开辟一块缓冲区
    ssize_t bytes_read;
    
    // 循环读取，直到 read 返回 0 (读完)
    while ((bytes_read = read(fd_in, buffer, sizeof(buffer))) > 0) {
        // 读到多少字节，就严格向外写多少字节
        write(fd_out, buffer, bytes_read);
    }
    
    close(fd_in);
    close(fd_out);
    printf("文件拷贝完成！\n");
    return 0;
}
```

## 五、 光标偏移操作：`lseek`

```c
#include <sys/types.h>
#include <unistd.h>
off_t lseek(int fd, off_t offset, int whence);
```
* **功能**：随意移动文件内部的读写光标，或者用来测算文件总大小。
* **参数**：
  * `offset`：偏移量（正数往后移，负数往前移，单位：字节）。
  * `whence`：定位基准点。
    * `SEEK_SET`：以文件开头为基准。
    * `SEEK_CUR`：以当前光标位置为基准。
    * `SEEK_END`：以文件末尾为基准。
* **返回值**：成功返回**偏移后，光标距离文件开头有多少个字节**；失败返回 `-1`。

### 💻 代码示例：巧妙获取文件大小
```c
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>

int main() {
    int fd = open("dest.txt", O_RDONLY);
    if (fd == -1) return -1;

    // 核心操作：将光标移动到文件末尾，偏移量为 0
    // 返回值就是文件末尾距离开头的字节数，也就是文件总大小！
    off_t size = lseek(fd, 0, SEEK_END);
    printf("该文件的总大小为: %ld 字节\n", size);

    // 如果后续还要读，记得把光标移回开头：
    // lseek(fd, 0, SEEK_SET);

    close(fd);
    return 0;
}
```

## 六、 附加实用技巧：跨系统文件传输

当你需要将 Windows 上的文件传输到 Linux（如 CentOS / Ubuntu）服务器上时，`scp` 指令是最高效的命令行工具：

1. 打开 Windows 的 cmd 或 PowerShell 窗口。
2. 输入传输指令（严格注意冒号不可省略）：
   ```bash
   scp 要拷贝的文件路径 Linux用户名@IP地址:/Linux存放的目标路径
   ```
   **示例：**
   ```bash
   scp C:\Users\test\code.cpp root@192.168.1.100:/home/root/code/
   ```
   然后输入 Linux 用户的密码，即可极速完成上传！
