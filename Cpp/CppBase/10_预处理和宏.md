# C++ 核心学习笔记：预处理指令 (Preprocessor)

## 一、 预处理的核心概念

1. **什么是预处理？**
   预处理是由**预处理程序**负责完成的。在对源文件进行正式编译（第一遍词法扫描和语法分析）**之前**，系统会自动调用预处理程序，对代码中所有的预处理指令进行处理。处理完毕后，才会自动进入真正的编译阶段。
2. **为什么需要预处理？**
   C++ 提供了多种预处理功能（如宏定义、文件包含、条件编译等）。合理使用它们，可以使程序：
   * 便于阅读、修改、移植和测试。
   * 极大地利于**模块化程序设计**。
3. **基本语法规则：**
   * 预处理命令主要是处理以 **`#`** 开头的指令（例如 `#include <iostream>`）。
   * 预处理命令一般要放在**所有函数之外**，并且通常习惯放在源文件的**最前面**（头部）。

## 二、 文件包含类 (File Inclusion)

用于将另一个源代码文件或头文件的内容，原封不动地“复制粘贴”到当前位置。

* **`#include <...>`**：引用编译器类库路径里的标准头文件。
* **`#include "..."`**：优先引用当前项目相对路径中的自定义头文件。

**代码示例：**
```cpp
#include <iostream>      // 包含标准输入输出流库
#include "my_math.h"     // 包含自定义的头文件

int main() {
    std::cout << "文件包含成功！" << std::endl;
    return 0;
}
```

## 三、 条件编译类 (Conditional Compilation)

条件编译允许编译器根据特定的条件，决定是否编译某一段代码。这在跨平台开发、调试代码、版本控制时非常有用。

* **`#if`**：如果给定条件为真，则编译下方代码。
* **`#ifdef`**：如果某个宏**已经定义**，则编译下方代码。
* **`#ifndef`**：如果某个宏**没有定义**，则编译下方代码（常用来防止头文件重复包含）。
* **`#elif`**：相当于 `else if`，如果前面的 `#if` 为假，且当前条件为真，则编译。
* **`#else`**：如果前面的所有条件都为假，则编译此处代码。
* **`#endif`**：结束条件编译块。

**代码示例：**
```cpp
#include <iostream>
using namespace std;

#define DEBUG_MODE 1  // 开启调试模式
#define VERSION 2     // 设定版本号

int main() {
    // 1. #ifdef 示例
#ifdef DEBUG_MODE
    cout << "[DEBUG] 调试模式已开启，正在输出日志..." << endl;
#endif

    // 2. #ifndef 示例
#ifndef RELEASE_MODE
    cout << "当前不是正式发布版本。" << endl;
#endif

    // 3. #if / #elif / #endif 示例
#if VERSION == 1
    cout << "正在运行 V1.0 基础版逻辑。" << endl;
#elif VERSION == 2
    cout << "正在运行 V2.0 升级版逻辑。" << endl;
#else
    cout << "未知版本。" << endl;
#endif

    return 0;
}
```

## 四、 宏定义类 (Macro Definition)

宏的本质是**纯文本替换**（也叫宏展开）。在编译预处理时，预处理程序会自动将程序中出现的所有“宏名”，无脑替换成宏定义中的“字符串/表达式”。

### 1. 无参数宏定义
通常用于定义常量。
* **语法**：`#define 标识符(宏名) 表达式或常量值`

**代码示例：**
```cpp
#include <iostream>
#define PI 3.14159       // 定义无参宏
#define MAX_BUFFER 1024

int main() {
    double radius = 2.0;
    // 预处理阶段，PI 会被自动替换为 3.14159
    double area = PI * radius * radius; 
    std::cout << "面积: " << area << std::endl;
    return 0;
}
```

### 2. 带参数宏定义 (宏函数)
C++ 中的宏函数跟普通函数类似，但**宏函数的参数是没有数据类型的**，因为它仅仅做字符串替换。

* **⚠️ 避坑指南：** 编写宏函数时，**务必给所有参数以及整个表达式加上括号**，以防止运算符优先级带来的逻辑错误。

**代码示例：**
```cpp
#include <iostream>

// 定义宏函数：求两个数的最大值
// 严谨写法：参数和外层都加了括号
#define MAX(a, b) ((a) > (b) ? (a) : (b))

// 定义宏函数：自增操作 (此处原笔记误放到了无参宏中)
#define INC(x) ((x)++) 

int main() {
    int x = 10;
    int y = 20;

    // 预处理时被替换为：int biggest = ((10) > (20) ? (10) : (20));
    int biggest = MAX(x, y); 
    std::cout << "最大值是: " << biggest << std::endl;

    // 预处理时被替换为：((x)++);
    INC(x); 
    std::cout << "x 自增后的值: " << x << std::endl; // 输出 11

    return 0;
}
```

### 3. 取消宏定义 (`#undef`)
如果在后续代码中不再需要某个宏，或者想重新定义它，可以使用 `#undef` 提前结束它的作用域。
* **语法**：`#undef 宏名`

**代码示例：**
```cpp
#include <iostream>

#define MODE 1

int main() {
    std::cout << "Mode is: " << MODE << std::endl;

#undef MODE // 从这一行开始，MODE 这个宏失效了

// 下面这行代码如果取消注释，编译器会报错，因为 MODE 已经被取消定义了
// std::cout << "Mode is: " << MODE << std::endl; 

    return 0;
}
```

### 4. 宏的高级操作符：`#` 与 `##`

**① `#` 字符串化操作符 (Stringification)**
* **作用**：将宏定义的参数直接转化为**字符串字面量**（相当于给参数加上双引号）。
* **代码示例**：
```cpp
#include <iostream>
using namespace std;

#define PRINT(a) cout << #a << " = " << (a) << endl;

int main() {
    float a = 3.0;
    // #a 会变成 "a*2+3"，而 (a) 会计算出真实结果
    PRINT(a * 2 + 3); 
    return 0;
}
// 最终输出：a * 2 + 3 = 9
```

**② `##` 连接操作符 (Token Pasting)**
* **作用**：将宏定义中的两个标识符（Token）无缝“粘”在一起，形成一个新的合法标识符（如变量名、函数名等）。
* **代码示例**：
```cpp
#define MEMBER(type, a) type m_##a

struct Demo {
    MEMBER(int, a);
    MEMBER(float, b);
};

// 预处理后，上面的结构体会被精确展开成：
/*
struct Demo {
    int m_a;
    float m_b;
};
*/
```

### 5. 多行宏定义 (`\`)

宏定义原则上只能写在一行。如果代码逻辑非常复杂（例如批量生成类的成员变量及 Get/Set 方法），可以在行尾加上反斜杠 `\` 作为**续行符**，告诉编译器下一行仍属于当前宏定义。

**代码示例（批量生成类属性）：**
```cpp
#define PROPERTY(Type, member) \
    private: \
        Type m_##member; \
    public: \
        const Type& get##member() const { return m_##member; } \
        void set##member(Type m) { m_##member = m; }

class Example {
    // 调用宏批量生成代码
    PROPERTY(int, age);
    PROPERTY(string, Name);
};

// 预处理后，最终得到的类结构如下（注意：## 不改变大小写）：
/*
class Example {
    private:
        int m_age;
    public:
        const int& getage() const { return m_age; }
        void setage(int m) { m_age = m; }
        
    private:
        string m_Name;
    public:
        const string& getName() const { return m_Name; }
        void setName(string m) { m_Name = m; }
};
*/
```

### 6. 编译器预定义宏 (Predefined Macros)

C/C++ 编译器内部自带了一些特殊的宏，它们在编译阶段会被自动替换为当前编译环境的真实信息，常用于日志记录或版本控制。

| 预定义宏 | 数据类型 | 描述说明 | 示例结果 |
| :--- | :--- | :--- | :--- |
| `__LINE__` | 整数 | 当前代码所在的行号 | `15` |
| `__FILE__` | 字符串 | 当前源文件的名称或路径 | `"main.cpp"` |
| `__DATE__` | 字符串 | 源代码被编译的日期 | `"Oct 18 2023"` |
| `__TIME__` | 字符串 | 源代码被编译的时间 | `"14:30:55"` |
| `__cplusplus` | 整数 | 编译器支持的 C++ 标准版本号 | `201402L` (C++14) |

### 7. 可变参宏函数 (Variadic Macros)

有时我们需要宏像 `printf` 那样接收不定数量的参数，这就需要用到可变参数宏。
* **`...`**：在宏参数列表中代表接收任意数量的参数。
* **`__VA_ARGS__`**：在宏展开体中，代表把 `...` 吸收到的所有参数原封不动地吐出来。

**代码示例（打造带位置追踪的日志系统）：**
```cpp
#include <stdio.h>

// 定义可变参宏：自动加上所在文件和行号
#define LOG(o, ...) fprintf(o, "[%s:%d] ", __FILE__, __LINE__); \
                    fprintf(o, __VA_ARGS__)

int main() {
    LOG(stdout, "%s\n", "测试信息，日志001");
    return 0;
}

// 编译器预处理时，最终会展开变成：
/*
fprintf(stdout, "[%s:%d] ", "D:\\Lesson\\20\\variadic.cpp", 9);
fprintf(stdout, "%s\n", "测试信息，日志001");
*/

// 控制台输出结果：
// [D:\Lesson\20\variadic.cpp:9] 测试信息，日志001
```
