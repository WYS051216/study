
## 一、变量定义与赋值

### 1. 声明变量

- 所有变量以 **`@`** 开头
- 使用 `DECLARE` 声明，可同时声明多个

```sql
-- 声明单个变量
DECLARE @name VARCHAR(20);

-- 声明并初始化
DECLARE @age INT = 25;

-- 同时声明多个
DECLARE @price DECIMAL(10,2) = 99.99,
        @quantity INT = 10,
        @total DECIMAL(10,2);
```

### 2. 赋值方式

```sql
-- 方式一：SET（推荐，一次赋一个值）
SET @name = '张三';

-- 方式二：SELECT（可从查询结果赋值）
SELECT @age = age FROM employees WHERE id = 1;

-- 方式三：SELECT 同时赋值多个变量
SELECT @price = price, @quantity = stock 
FROM products WHERE product_id = 100;
```

**注意**：如果 `SELECT INTO` 变量时查询返回多行，变量只会得到**最后一行**的值。

## 二、基础运算

| 类型                 | 运算符                                           | 示例                                |
| -------------------- | ------------------------------------------------ | ----------------------------------- |
| **算术**       | `+` `-` `*` `/` `%`                    | `SET @result = (10 + 20) * 2`     |
| **比较**       | `=` `>` `<` `>=` `<=` `<>`（不等于） | `IF @age >= 18`                   |
| **逻辑**       | `AND` `OR` `NOT`                           | `WHERE price > 100 AND stock > 0` |
| **字符串连接** | `+`                                            | `'Hello' + ' ' + 'World'`         |
| **NULL检查**   | `IS NULL` / `IS NOT NULL`                    | `WHERE @name IS NULL`             |
| **字符串匹配** | `LIKE`（支持 `%` `_`）                     | `WHERE name LIKE '张%'`           |
| **范围判断**   | `BETWEEN ... AND ...`                          | `WHERE age BETWEEN 18 AND 60`     |
| **集合判断**   | `IN`                                           | `WHERE city IN ('北京','上海')`   |

## 三、流程控制（条件判断）

### 1. IF...ELSE 结构

```sql
DECLARE @score INT = 85;

IF @score >= 90
BEGIN
    PRINT '优秀';
    -- 可写多行语句
END
ELSE IF @score >= 60
BEGIN
    PRINT '及格';
END
ELSE
BEGIN
    PRINT '不及格';
END
```

**要点**：

- `BEGIN...END` 相当于代码块（类似 C 语言的 `{ }`）
- 如果只有单条语句，`BEGIN...END` 可以省略（但建议保留）

### 2. CASE 表达式（两种写法）

在普通 SQL 查询中使用，**不是流程控制语句**。

```sql
-- 简单 CASE（等值判断）
SELECT 
    name,
    CASE grade
        WHEN 'A' THEN '优秀'
        WHEN 'B' THEN '良好'
        WHEN 'C' THEN '及格'
        ELSE '不及格'
    END AS 等级描述
FROM students;

-- 搜索 CASE（条件判断，更灵活）
SELECT 
    name,
    CASE 
        WHEN score >= 90 THEN '优秀'
        WHEN score >= 60 THEN '及格'
        ELSE '不及格'
    END AS 等级
FROM students;
```

## 四、循环结构

SQL Server 只有 **`WHILE`** 循环（没有 `FOR` 或 `LOOP`）。

### 1. 基本 WHILE 循环

```sql
DECLARE @i INT = 1;
DECLARE @sum INT = 0;

WHILE @i <= 10
BEGIN
    SET @sum = @sum + @i;
    SET @i = @i + 1;
END

PRINT '1到10的和为：' + CAST(@sum AS VARCHAR);  -- 输出 55
```

### 2. 循环控制：BREAK 和 CONTINUE

```sql
DECLARE @i INT = 1;

WHILE @i <= 20
BEGIN
    -- 跳过偶数
    IF @i % 2 = 0
    BEGIN
        SET @i = @i + 1;
        CONTINUE;  -- 跳过本次循环剩余代码
    END
  
    PRINT @i;  -- 只打印奇数
  
    -- 到 15 就提前结束
    IF @i >= 15
        BREAK;  -- 退出循环
  
    SET @i = @i + 1;
END
```

## 五、SQL Server 特有函数和常用技巧

### 1. 数据类型转换

```sql
-- CAST（标准）
CAST(123 AS VARCHAR)

-- CONVERT（SQL Server 特有，支持日期格式）
CONVERT(VARCHAR, GETDATE(), 120)  -- 输出 '2026-06-18 10:30:25'
```

### 2. 日期处理

```sql
GETDATE()          -- 当前日期时间
DATEPART(YEAR, GETDATE())   -- 提取年份
DATEADD(DAY, 7, GETDATE())  -- 7天后
DATEDIFF(DAY, '2026-01-01', GETDATE())  -- 相差天数
```

### 3. 字符串函数

```sql
LEN(@str)         -- 长度（不含尾部空格）
CHARINDEX('子串', @str)  -- 查找位置
SUBSTRING(@str, 1, 5)   -- 截取
REPLACE(@str, '旧', '新')
UPPER(@str) / LOWER(@str)
```

### 4. 系统变量（常用）

```sql
@@ROWCOUNT        -- 上次SQL影响的行数
@@FETCH_STATUS    -- 游标读取状态（0=成功）
@@IDENTITY        -- 最后插入的标识列值
@@ERROR           -- 上次错误号（0=无错误）
```

## 六、重要原则与避坑指南

| 原则                             | 说明                                                                           |
| -------------------------------- | ------------------------------------------------------------------------------ |
| **避免游标**               | 游标逐行处理效率极低，能用`UPDATE`/`INSERT...SELECT` 批量操作就优先用      |
| **事务处理**               | 批量更新时用`BEGIN TRAN...COMMIT/ROLLBACK` 保证一致性                        |
| **NULL处理**               | 任何与`NULL` 的运算结果都是 `NULL`，用 `ISNULL()` 或 `COALESCE()` 处理 |
| **SET vs SELECT 赋值**     | `SET` 更安全（只给一个变量），`SELECT` 可从查询批量赋值                    |
| **BEGIN...END 一定要配对** | 每个`IF`/`WHILE` 下如果有多条语句，必须用 `BEGIN...END` 包裹             |

## 七、快速参考速查

```sql
-- ===== 变量 =====
DECLARE @var VARCHAR(20) = '值';
SET @var = '新值';
SELECT @var = column FROM table WHERE id = 1;

-- ===== 条件 =====
IF @value > 10
BEGIN
    -- 多条语句
END
ELSE
BEGIN
    -- 否则
END

-- ===== 循环 =====
WHILE @i <= 100
BEGIN
    IF @i % 2 = 0 CONTINUE;  -- 跳过偶数
    IF @i > 50 BREAK;        -- 超过50退出
    PRINT @i;
    SET @i = @i + 1;
END

-- ===== CASE =====
SELECT CASE WHEN @score >= 60 THEN '及格' ELSE '不及格' END;

-- ===== 错误处理 =====
BEGIN TRY
    -- 可能出错的代码
END TRY
BEGIN CATCH
    PRINT ERROR_MESSAGE();  -- 打印错误信息
END CATCH
```

## 八、PRINT 命令（最常用）

### 1. 基本用法

```sql
PRINT 'Hello World';
PRINT '当前时间：' + CONVERT(VARCHAR, GETDATE(), 120);
```

### 2. 打印变量值

```sql
DECLARE @name VARCHAR(20) = '张三';
DECLARE @age INT = 30;
PRINT '姓名：' + @name + '，年龄：' + CAST(@age AS VARCHAR);
-- 输出：姓名：张三，年龄：30
```

### 3. 打印多行

```sql
PRINT '第一行';
PRINT '第二行';
PRINT '第三行';
-- 每条 PRINT 单独输出一行
```

### 4. 在循环中打印进度

```sql
DECLARE @i INT = 1;
WHILE @i <= 10
BEGIN
    PRINT '当前第 ' + CAST(@i AS VARCHAR) + ' 次循环';
    SET @i = @i + 1;
END
```
