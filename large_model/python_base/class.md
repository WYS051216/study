# Python 面向对象（OOP）基础与魔术方法笔记

## 1. 类的设计与定义
使用 `class` 关键字定义类，类中可以包含属性（成员变量）和方法（成员方法）。

```python
class Student:
    # 属性（类变量，通常可以在 __init__ 中定义实例变量替代）
    name = None
    
    # 构造方法：创建对象时自动执行，用于初始化属性
    def __init__(self, name, age):
        self.name = name  # 实例属性赋值
        self.age = age

    # 成员方法
    def function(self):
        # 方法体
        pass
```

## 2. 成员方法与 `self` 关键字
**定义语法：**
```python
def 方法名(self, 形参1, 形参2...):
    方法体
```
* **`self` 的作用**：表示类对象自身。当使用类对象调用方法时，Python 会自动将该对象作为第一个参数传入。
* **访问成员**：在类的方法内部，如果想要访问类的成员变量或其他成员方法，**必须**使用 `self.成员变量名` 或 `self.方法名()`。

## 3. 对象的创建与使用
**创建对象（实例化）：**
```python
stu_1 = Student("张三", 18) # 创建时会自动将参数传递给 __init__ 方法
```
**对象属性赋值与访问：**
```python
stu_1.name = "李四"      # 修改属性值
print(stu_1.name)        # 访问属性值
stu_1.function()         # 调用成员方法
```

## 4. 常用内置方法（魔术方法 Magic Methods）
Python 中以双下划线开头和结尾的方法称为魔术方法，它们会在特定的操作下自动触发。

| 魔术方法 | 触发时机与作用 | 代码示例 / 对应操作 |
| :--- | :--- | :--- |
| **`__init__(self, ...)`** | **构造方法**：在创建类对象时自动执行，用于初始化实例属性。 | `obj = MyClass()` |
| **`__str__(self)`** | **字符串方法**：控制将对象转化为字符串的行为，用于给用户看（`print` 触发）。必须返回字符串。 | `print(obj)` 或 `str(obj)` |
| **`__repr__(self)`** | **开发者字符串方法**：类似于 `__str__`，但主要用于开发者调试，通常返回可以直接执行的实例化代码形式。 | `repr(obj)` 或 交互模式输出 |
| **`__len__(self)`** | **长度方法**：当使用 `len()` 函数获取对象长度时触发，必须返回整数。 | `len(obj)` |
| **`__del__(self)`** | **析构方法**：当对象被销毁（内存回收）前自动调用，常用于关闭文件或释放资源。 | `del obj` 或 程序结束 |
| **`__call__(self, ...)`** | **可调用方法**：使类的实例对象可以像函数一样被直接调用。 | `obj()` |

### 比较运算符重载方法
用于定义对象之间的比较规则（例如按年龄、成绩等属性进行比较）：

| 魔术方法 | 对应符号 | 作用说明 |
| :--- | :--- | :--- |
| **`__lt__(self, other)`** | `<` | **L**ess **T**han：小于比较 |
| **`__le__(self, other)`** | `<=` | **L**ess than or **E**qual to：小于等于比较 |
| **`__eq__(self, other)`** | `==` | **EQ**ual to：等于比较。如果不实现该方法，默认比较对象的内存地址。 |
| **`__ne__(self, other)`** | `!=` | **N**ot **E**qual to：不等于比较 |
| **`__gt__(self, other)`** | `>` | **G**reater **T**han：大于比较 |
| **`__ge__(self, other)`** | `>=` | **G**reater than or **E**qual to：大于等于比较 |

## 5. 封装：定义私有成员
- **私有成员变量**：变量名以 `__`（双下划线）开头。
- **私有成员方法**：方法名以 `__`（双下划线）开头。
- **访问权限**：类外面**无法**直接使用私有成员变量和方法；类里面的其他方法可以正常访问这些私有成员。

## 6. 继承的基础语法
继承分为**单继承**和**多继承**，可以将父类的属性和方法传递给子类。
```python
class 子类名(父类1, 父类2, ...):
    # 类内内容（属性和方法）
    pass
```

## 7. `pass` 关键字
- **作用**：补全语法空白，保证代码结构的完整性，本身不执行任何操作。
- **与抽象方法**：如果一个函数或方法体内只有 `pass`，那么这个方法通常被当作**抽象方法**，具体的实现逻辑交由继承它的子类自行决定和编写。

## 8. 多继承的注意事项
- 当一个类继承多个父类时，如果多个父类中存在**同名的成员（属性或方法）**，默认按照继承列表中的顺序（**从左到右**）来决定优先级。
- **即：先继承的（靠左的）保留，后继承的被覆盖。**

## 9. 复写（Overriding）与调用父类成员
子类继承父类的成员属性和成员方法后，可以对其进行**复写**（在子类中重新定义同名的属性或方法）。

如果在子类中需要调用被复写的父类成员，可以使用以下两种特殊调用方式：
- **方式 1：使用父类名**
  - 调用变量：`父类名.成员变量`
  - 调用方法：`父类名.成员方法(self)` （注意：必须手动传入 `self`）
- **方式 2：使用 `super()` （推荐）**
  - 调用变量：`super().成员变量`
  - 调用方法：`super().成员方法()` （注意：不需要传 `self`）

## 10. 类型注解 (Type Hint)
用于提示变量、参数或返回值的类型，帮助开发者和 IDE 识别数据类型，但不会强制限制代码的运行。
- **基础数据类型注解**：
  ```python
  var_1: int = 10
  name: str = "Tom"
  ```
- **类对象类型注解**：
  ```python
  class Student:
      pass
  
  stu: Student = Student()
  ```

## 11. 多态 (Polymorphism)
**多态**的意思是“多种状态”。在面向对象编程中，指的是**同一个行为（方法），不同的对象具有不同的表现形式。**

- **实现条件**：通常依赖于**继承**和**方法的复写**。父类提供一个统一的方法（往往是带有 `pass` 的抽象方法），不同的子类继承后各自给出不同的具体实现。
- **核心逻辑**：以父类作为统一的参数类型声明，但实际传入的是不同的子类对象，从而执行出不同的结果。
- **代码示例**：
  ```python
  class Animal:
      def speak(self):
          pass  # 抽象方法，由子类实现

  class Dog(Animal):
      def speak(self):
          print("汪汪汪！")

  class Cat(Animal):
      def speak(self):
          print("喵喵喵！")

  # 定义一个统一的调用接口，类型注解声明为父类 Animal
  def make_animal_speak(animal: Animal):
      animal.speak()

  # 传入不同的子类对象，产生不同的行为（多态的体现）
  dog = Dog()
  cat = Cat()
  
  make_animal_speak(dog)  # 输出: 汪汪汪！
  make_animal_speak(cat)  # 输出: 喵喵喵！
  ```
