# Python 函数核心知识点总结

## 1. 函数的基础
### 1.1 函数的定义
使用 `def` 关键字定义函数。
```python
def 函数名(传入参数):
    函数体
    return 返回值
```

### 1.2 函数的调用
通过函数名和参数来执行函数：
```python
函数名(参数)
```

### 1.3 函数的说明文档（Docstring）
使用多行注释的形式，对函数的功能、参数和返回值进行说明解释。习惯上放在函数定义的第一行。
```python
def add(a, b):
    """
    计算两个数的和。
    
    :param a: 第一个加数
    :param b: 第二个加数
    :return: 两数之和
    """
    return a + b
```

## 2. 函数的参数传递
传入参数的作用是在函数进行计算时，接受外部提供的数据。参数数量不限，可以没有，也可以有多个。

### 2.1 位置参数
调用函数时，根据参数的**定义位置**来传递参数。传递的参数顺序必须和定义时严格一致。

### 2.2 关键字参数
调用函数时，通过 `键=值` 的形式来传递参数。
* **作用**：让代码更清晰，解除了参数的顺序限制。
* **⚠️ 注意事项**：可以和位置参数混用，但**位置参数必须在关键字参数的前面**。

### 2.3 缺省参数（默认参数）
定义函数时，为参数提供一个默认值。调用时如果不传该参数，就会使用默认值。
* **⚠️ 语法规则**：定义时，缺省参数必须放在**非缺省参数的后面**。
* **⚠️ 避坑指南**：默认参数尽量不要使用可变对象（如列表 `[]` 或字典 `{}`），否则会引发不可预期的共享修改问题，建议使用 `None` 代替。

### 2.4 不定长参数（可变参数）
用于不确定调用时会传递多少个参数的场景。
* **位置不定长（`*args`）**：
  * 接收任意数量的位置参数。
  * 在函数内部，这些参数会被组装成一个**元组 (Tuple)**。
* **关键字不定长（`**kwargs`）**：
  * 接收任意数量的关键字参数（即 `key=value` 形式）。
  * 在函数内部，这些参数会被组装成一个**字典 (Dictionary)**。

```python
# 综合演示
def demo_func(a, b=2, *args, **kwargs):
    print(f"a={a}, b={b}, args={args}, kwargs={kwargs}")

demo_func(1, 3, 4, 5, name="Joel", age=20) 
# 输出: a=1, b=3, args=(4, 5), kwargs={'name': 'Joel', 'age': 20}
```

## 3. 函数的返回值

### 3.1 基础返回值
`return` 关键字用于将程序计算的结果返回给调用者。遇到 `return`，函数立即结束。

### 3.2 函数的多返回值
可以通过 `return` 一次性返回多个值，各个值之间用逗号隔开。
* **本质**：Python 会自动将这些值封装成一个**元组 (Tuple)**返回。
* **接收变量**：可以用对应数量的变量（如 `x, y = 函数()`）进行解包接收。
```python
def get_point():
    return 10, 20  # 本质上返回的是 (10, 20)

x, y = get_point() # x=10, y=20
```

### 3.3 None 类型
如果一个函数没有写 `return`，或者写了 `return` 但后面没有跟值，函数默认返回 `None`。
* **用途 1**：表示函数无具体返回值。
* **用途 2**：用在 `if` 判断上，`None` 等同于 `False`。
* **用途 3**：定义变量时作为初始占位符（如暂不需要具体值，用 `None` 代替）。

## 4. 变量的作用域

作用域指的是变量生效的范围。

### 4.1 局部变量与全局变量
* **局部变量**：定义在函数体内部的变量，只在函数体内部生效。
  * **作用**：临时保存数据，当函数执行完成后，局部变量会被立即销毁（释放内存）。
* **全局变量**：定义在函数体外的变量，在函数体内、外都能读取。

### 4.2 global 关键字
如果在函数内部需要**修改**外部的全局变量，必须先使用 `global` 关键字声明。
```python
count = 0
def update_count():
    global count  # 声明修改的是全局变量
    count += 1
```

### 4.3 nonlocal 关键字（补充）
用在**嵌套函数**中。如果内部函数想要修改外部函数（非全局）的局部变量，需要使用 `nonlocal` 关键字。

## 5. 函数进阶

### 5.1 函数的嵌套调用与嵌套定义
* **嵌套调用**：一个函数里面调用另一个函数。
* **嵌套定义**：一个函数的函数体内部定义了另一个函数（常用于闭包和装饰器）。

### 5.2 Lambda 匿名函数
当函数逻辑非常简单，且只使用一次时，可以使用 `lambda` 定义匿名函数。
* **语法**：`lambda 传入参数: 表达式`
* **⚠️ 注意事项**：
  * `lambda` 冒号后面只能跟**单行表达式**，不能包含复杂的逻辑块（如 `while` 循环、多行 `if` 等）。
  * 表达式的计算结果会自动被 `return`，不需要额外写 `return` 关键字。
```python
# 常用于作为参数传递，例如列表排序
my_list = [(1, 2), (3, 1), (5, 0)]
my_list.sort(key=lambda x: x[1])  # 按照元组的第二个元素排序
```
