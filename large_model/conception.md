## 1. 核心概念

* **LLM (Large Language Model)**: 大语言模型。
* **Token**: 大模型处理文本的基本单位。
  * **输入与输出**: 模型接受和返回的都是数字。
  * **Tokenizer (分词器)**: 负责编码和解码，实现文字与数字（Token ID）之间的互相转换。
  * **工作原理**:
    1. **切分与映射 (编码)**: 首先将用户输入的问题进行切分，把每一个 Token 映射成一个唯一的数字。这段文字会变成一串由 Token ID 组成的列表。
    2. **模型计算**: 在模型内部进行复杂的矩阵计算。
    3. **逐字返回 (解码)**: 将返回的数字解码为文字输出。输出时不需要切分，因为模型是逐个 Token 进行生成和返回的。
  * **换算参考**: 平均来讲，1 个 Token 约等于 0.75 个英文单词，或 1.5 - 2 个汉字。

## 2. 上下文与记忆机制

* **Context (上下文)**: 每次跟大模型进行对话的时候，系统会自动把以前的对话历史一起发送过去，作为模型理解当前语境的参考。
* **Context Window (上下文窗口)**: Context 能容纳的最大 Token 数量（即模型的记忆长度限制）。
* **RAG (Retrieval-Augmented Generation)**: 检索增强生成。（*注：通过在给大模型提问前，先去外部知识库检索相关文档，并将其一起发给大模型，从而提高回答的准确性并减少幻觉*）。

## 3. 交互与工具生态

* **Prompt (提示词)**: 大模型接收的具体问题或指令。
  * **User Prompt**: 用户输入的提示词。
  * **System Prompt**: 后台设置的系统级提示词（通常用于设定人设或全局规则）。
* **Tool (工具)**: 本质上是函数，给输入就有输出。它给大模型提供了一套可以调用的外部能力，让大模型能够感知和影响外部环境（如查天气、搜索网页、执行代码等）。
* **MCP (Model Context Protocol)**: 统一的工具接入规范。

## 4. 智能体与进阶应用

* **Agent (智能体)**: 能够自主规划、自主调用工具、持续运作，直至解决用户复杂问题的 AI 系统。
* **Agent Skill (智能体技能)**: 
  * **定义**: 提前写好并塞给 Agent 的一份说明文档，本质上就是一个 Markdown 文档。格式没有具体要求，只要给 Agent 描述清楚执行逻辑就行。
  * **存放与配置 (以 Claude 为例)**: 
    1. 切换到 `.claude` 文件夹下的 `skills` 文件夹。
    2. 新建一个文件夹，名称必须和 Skill 的名称完全一样。
    3. 在该文件夹下面新建一个命名为 `SKILL.md` 的文件。
    4. 将技能的说明内容粘贴进去即可生效。
 
## 5. 模型参数与生成控制

* **生成机制 (大模型的底层原理)**: 模型预测下一个词汇的过程通常包含三个核心步骤：
  1. **生成分数**: 模型首先为词汇表中的每个候选词计算出一个原始的分数（Logits）。
  2. **转换概率 (Softmax 函数)**: 利用 Softmax 函数，将这些难以直接比较的原始分数，转换为所有候选词加起来总和为 1 的概率分布。
  3. **加权采样**: 模型并不总是直接选择概率最高的那一个词，而是根据转换后的概率分布进行加权随机抽样，从而决定最终输出的具体文字。

* **Temperature (温度值)**: 用于控制 Softmax 函数处理后概率分布的平缓程度，是调节大模型输出随机性的核心参数。
  * **高 Temperature**: 概率分布会被拉平，缩小高分词与低分词的差距，原本概率较低的词也有更大的机会被选中。**随机性越强，越有创造力**（适合公文写作、故事创作、头脑风暴）。
  * **低 Temperature**: 概率分布会变得更加陡峭，高概率的词会占据绝对优势。**输出越稳定、越确定**（适合代码生成、数学计算、事实问答、数据提取）。

* **Top P (核采样 / Nucleus Sampling)**: 另一种控制随机性的方式，主要用于截断候选词的范围，控制采样池的大小。
  * **工作原理**: 将所有候选词按概率从高到低排序，然后不断累加概率，直到累加值刚好达到设定的 P 值（例如 0.9）。模型只会从这个累计概率范围内的词汇集合中进行抽样，直接抛弃掉尾部极小概率的“长尾”词汇。
  * **高 Top P**: 设定的阈值较高（如 0.95），候选词池子更大，包含更多可能，增加表达的多样性。
  * **低 Top P**: 设定的阈值较低（如 0.5），候选范围被严格限制在最核心的少数几个高频词中，减少跑题的风险，进一步提高准确性和稳定性。
